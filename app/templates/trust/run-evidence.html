Run evidence shows that a stored result is internally consistent and has not been altered. It does not show that the assumptions are right.

What it is

  • Each committed Last Run is checked by deterministic recomputation. There is no model call, no market data and no fuzzy matching.
  • A check that lacks evidence reports Unavailable, never Pass.
  • A Last Run can be signed with an Ed25519 key. Anyone can verify the signature without signing in.

What it is not

  • It is not an audit opinion and not a statement that the inputs are correct.
  • It does not check a Working Copy, only a committed run.
