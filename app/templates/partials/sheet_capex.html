These six items are CAPEX detail columns that the current runtime does not yet consume. They are captured for design / planning, will be visible in audit exports, and are documented here as a forward-looking contract.

  • Metadata-only VAT % / WHT % / Contingency % — captured in CAPEX detail columns; not yet fed to tax / model.
  • Design-only Payment schedule by construction month — equity / senior / SHL drawdown, IDC, opening balances at COD.
  • Design-only Depreciation category / useful life / flag — P&L and fixed asset schedule.
  • Design-only VAT applicability / rate / cost — cash flow / balance sheet / working capital / tax receivable.
  • Design-only WHT rate / cost — tax / cash flow treatment.
  • Design-only Utilisation of funds during construction — derived from the payment schedule.
{# ── Sources & Uses bridge (future model wiring) ─────────────── #}

Sources & Uses bridge (future model wiring): this CAPEX sheet is one of the core input engines. Once VAT / WHT / depreciation / payment schedule are wired, the CAPEX inputs will feed drawdowns (equity / senior / SHL), IDC, opening debt balances at COD, fixed asset base, tax and cash flow.

What feeds what: Payment schedule → Sources & Uses, equity / senior / SHL drawdown, IDC. VAT / WHT rates → cash flow, balance sheet, tax receivable / payable. Depreciation flags → P&L, fixed asset schedule. Cumulative drawdowns → opening senior and SHL balances at COD.

This sheet is a UI input surface; the backend model wiring above is a separate, larger effort and is not implemented in this UI phase.
