FINCO Protocol
FINCO Protocol is financial intelligence infrastructure. FINCO Model is the deterministic modelling workspace for real-asset and infrastructure analysis.

Workflow
1. Select a model — open a protected reference or create a working model.
2. Review assumptions — inspect project, revenue, CAPEX, OPEX, financing and tax inputs.
3. Save a scenario — preserve a named input state before making material changes.
4. Run model — the backend engine calculates financial outputs.
5. Review results — inspect returns, coverage, cash flows and statements.
6. Export — exports reflect the last completed backend run.
Important boundaries
Reference models use synthetic assumptions and are not representations of any real project, company, client or jurisdiction.
Outputs are financial modelling estimates and do not constitute legal, tax, accounting, credit or investment advice.
Browser-side JavaScript is presentation-only; financial calculations remain backend-authored.
