Model API

Reference Models

Canonical synthetic Solar and Wind reference models. Read-only endpoints return reference assumptions. The run endpoint executes one canonical financial calculation and returns summary KPIs. No project is created.

Method
Path
Description
GET
/api/v1/model/references
List canonical synthetic Solar/Wind reference models.
GET
/api/v1/model/references/{reference_key}
Read one canonical reference assumption set in full.
GET
/api/v1/model/references/{reference_key}/capex
Read canonical CAPEX authority for one reference.
GET
/api/v1/model/references/{reference_key}/opex
Read canonical OPEX authority for one reference.
POST
/api/v1/model/references/{reference_key}/preview
Preview capacity-scaled CAPEX/OPEX without creating a project or running the engine.
Stateless No project created No model run
POST
/api/v1/model/references/{reference_key}/run
Stateless canonical model run. Executes one financial calculation and returns summary KPIs.
Stateless Canonical model run No project created Capacity-only input
Radar API

Market Intelligence

Tokenized-equity asset universe, fundamentals, financials and execution simulation. All endpoints are read-only.

Method
Path
Description
GET
/api/v1/radar/assets
List all canonical Radar assets from the current registry snapshot.
GET
/api/v1/radar/assets/{economic_asset_uid}
Return canonical identity for one asset.
GET
/api/v1/radar/assets/{economic_asset_uid}/fundamentals
Return latest TTM/quarterly/annual fundamentals and company profile.
GET
/api/v1/radar/assets/{economic_asset_uid}/financials
Return multi-period financial history (annual, quarterly, TTM).
GET
/api/v1/radar/assets/{economic_asset_uid}/corporate-actions
Return recent dividend and stock split history.
GET
/api/v1/radar/assets/{economic_asset_uid}/evidence
Return source lineage and evidence for one asset.
POST
/api/v1/radar/assets/{economic_asset_uid}/execution-simulation
Read-only execution simulation analytics. Returns reference price, executable price and directional GAP.
Read-only simulation No order submitted
Quick Start

Examples

List model references
curl {{ api_base_url }}/model/references
Preview Solar at 100 MW (stateless — no project created)
curl -X POST \
  {{ api_base_url }}/model/references/generic_solar_reference/preview \
  -H "Content-Type: application/json" \
  -d '{"capacity_mw":100}'
