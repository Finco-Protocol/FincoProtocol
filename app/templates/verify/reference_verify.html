How to Verify (Outsider Steps)
  1. 1

    Install the required signature dependency

    Required for full PASS. Ed25519 issuer signature verification is mandatory — hash checks alone prove content integrity but do not prove FINCO issued the certificate. 

    pip install pycryptodome
  2. 2

    Download the verifier script

    No FINCO internal code, no internal packages. Requires Python stdlib + pycryptodome.

    curl -O {{ request.base_url | string | trim('/') }}{{ base_path }}/verify.py
  3. 3

    Run the verifier

    Exits 0 on full PASS (all four checks including issuer signature), non-zero on any FAIL.

    python verify.py --base-url {{ request.base_url | string | trim('/') }}
Full PASS requires all four checks: (1) assumptions hash matches certificate, (2) outputs hash matches certificate, (3) certificate digest is self-consistent, (4) FINCO's Ed25519 issuer signature is valid. A single modified byte in any artifact causes FAIL. If pycryptodome is absent, the verifier exits with a non-zero failure — it never returns PASS without signature verification.

Hash checks (1–3) prove content integrity and self-consistency. Ed25519 signature (4) proves FINCO issued this exact certificate — not that the underlying economic results are correct, that external data is authentic, or that the asset has been audited or anchored on-chain.

Use --integrity-only for hash-only inspection; this outputs INTEGRITY CHECK ONLY and never PASS.
Verification Algorithm
StepWhatHow
1 Assumptions hash SHA-256(FINCO_SORTED_JSON_V1(assumptions.json)) == certificate.identity.assumptions_sha256
2 Outputs hash SHA-256(FINCO_SORTED_JSON_V1(outputs.json)) == certificate.identity.outputs_sha256
3 Certificate digest SHA-256(FINCO_SORTED_JSON_V1(cert_without_id_digest)) == certificate.certificate_digest_sha256
4 Issuer signature Ed25519.verify(public-key.pem, FINCO_SORTED_JSON_V1(certificate.json), signature.signature_b64)
FINCO_SORTED_JSON_V1: json.dumps(obj, sort_keys=True, separators=(",",":"), ensure_ascii=False) encoded as UTF-8. The signature proves FINCO issued this exact certificate — not that the underlying economic results are correct or that external data is authentic.
