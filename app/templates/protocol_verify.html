Trust & Verification

FINCO separates several verification authorities. They are not cumulative: a result at one layer never implies another.

Run Integrity Checks — SHIPPED

Read-only checks over the evidence recorded when a run is committed: Sources & Uses, balance-sheet reconciliation, senior debt rollforward, debt-service/interest consistency, CFADS/DSCR integrity, DSCR sculpting feasibility, unfunded-cash conditions and sponsor-return input consistency. Recomputed from recorded evidence; they never re-run the model. They do not validate external assumptions and are not economic truth. In-product: the Model Trust Pack in the V2 workbook.

Reference Regression Check — SHIPPED

Re-runs canonical reference models against pinned expected outputs and tolerances. Regression protection for the reference library. It does not validate a user's Last Run and is not a model-soundness guarantee. Distinct from Run Integrity.

Signed Run Certificate — SHIPPED (config-gated)

Ed25519 signatures over the exact committed run evidence (FINCO_RUN_CERTIFICATE_V1). Issuance requires FINCO_RUN_CERT_SIGNING_KEY and fails closed without it. Signature verification works when the relying party holds the trusted public key; public trust-key distribution and a public verifier are in development (M-2). No blockchain anchoring is implemented. Signed Run is not FINCO Verify and not economic truth.

FINCO Verify — separate binding authority

Source-attested binding of a model/asset to a claimed external identity. Requires explicit on-chain evidence with a confirmed evidence_id. Production boundary: Verified production assets: 0. Current records render MODEL_ONLY — MODEL_ONLY never means VERIFIED.
