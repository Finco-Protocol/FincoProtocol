# Public Data Policy

The corporate repository must contain only generic, synthetic, or explicitly public data.

Not permitted:
- client or employer names,
- real project names or SPV identifiers,
- reference methodology names or uploaded workbooks,
- production databases or saved projects,
- project-specific screenshots, exports, logs or calibration reports,
- personal email addresses, local user paths or credentials,
- historical private Git metadata.

Synthetic references must use new assumptions rather than lightly modified copies of a real project.
