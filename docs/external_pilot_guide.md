# FINCO Protocol — External Pilot Guide

Welcome to the FINCO Protocol pilot. This guide covers the three product
surfaces and how to get started.

---

## Product Surfaces

### FINCO Model

The Model surface is a deterministic infrastructure-finance workbook.

Getting started:
1. Open Model Library at /library.
2. Select or create a project.
3. Edit project inputs (capacity, CAPEX, operating assumptions).
4. Run the model to produce revenue, cash flow, debt service, and returns.
5. Review outputs under Results — each value carries a derivation lineage.
6. Export an institutional-grade report with evidence lineage.

Key outputs: Production · Revenue · CAPEX · Debt service · DSCR · IRR ·
Cash flow · Distributions.

### FINCO Radar

The Radar surface is a market-intelligence terminal for tokenized real-world
assets.

Getting started:
1. Open Radar at /radar.
2. Select an asset from the Featured Equities board or the asset selector.
3. View company fundamentals and financial history.
4. Inspect Reference · Executable · Directional GAP panels.
5. Open the Company Terminal for full equity detail.

Execution simulation is coming soon. No wallet, signing, or transaction
submission is available in the current release.

### FINCO Verify

The Verify surface provides deterministic evidence verification.

Getting started:
1. Open Verify at /verify.
2. Enter a number and its claimed derivation source.
3. Verify against the public synthetic corpus.
