## 7. Pitfalls already hit (don't repeat)
Unconstrained pip → wrong fastapi. `monkeypatch.undo()` also removes env flags → use `monkeypatch.context()`. Same-URL `page.goto` with a hash is a hash navigation → `page.reload()` after. Playwright `params=[(…)]` mis-encodes → build the query string manually. Library `total_all`/facets must count ALL projects (search applied only in `keep()`). Don't run `pkill -f "pytest …"` from a shell whose command line contains the pattern (it kills itself). Don't rebuild the bundle while a browser run is in progress. Regex `/CAS/i` matches "CASH" — use `/(^|_)CAS(_|$)/`.
