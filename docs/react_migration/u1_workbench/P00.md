## 3. Economic authority (each visible money value → one writer)

| Visible value | Writer | Route |
|---|---|---|
| CAPEX line amount, description, notes | cost-line batch save | `POST /v2/workbook/grid/cost-lines/save` |
| New line (CAPEX / OPEX) | line add | `POST /v2/{capex\|opex}/line/add` |
| Retire / reactivate | line commands | `POST /v2/{capex\|opex}/line/{deactivate\|reactivate}` |
| OPEX line amount, inflation | cost-line batch save | as above |
| OPEX group base amount (six) | canonical cell writer (Save All `cells`) | `POST /v2/workbook/save-all` / `POST /v2/workbook/grid/save` |
| CAPEX monthly profile | profile document save | `POST /v2/capex/spending-profiles/save` |
| per MW, totals, cards, Years | none: read-only projections of the above | `GET /v2/model-react/costlines`, `…/opex-projection` |

## 4. Save boundaries (unchanged)

Cost lines: one atomic batch. OPEX base amounts: cells, saved with lines by Save changes (top bar or the OPEX footer button). CAPEX profile: its own document and Save. Financing keeps its own Save. No save runs the model; no claim of one atomic transaction across lines and profile.
